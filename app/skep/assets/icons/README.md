# Icons

Phosphor Icons, thin weight, from https://phosphoricons.com. MIT licensed; the
licence sits beside them in LICENSE and covers every file in this directory.

The thin weight is filled geometry rather than strokes: the shapes are 8 units
thick in a 256 unit box, so an icon drawn at 16px has a half point edge. That
lands on exactly one device pixel on a retina display, which is the whole point
of the weight, and would turn to grey mush anywhere else. Skep is Apple silicon
only, so anywhere else does not arise.

Icons are chosen to lean geometric rather than pictorial, because a skep is a
straw beehive and the engine inside it is called comb.
